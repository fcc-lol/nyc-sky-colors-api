MCP Documentation

NYC Sky Colors runs a public Model Context Protocol server, so Claude and other AI assistants can look up the color of the sky over New York City, now or at any recorded moment in the past.

Connect

Server URL https://nyc-sky-colors.fcc.lol/mcp
Transport Streamable HTTP (stateless, POST only)
Authentication None. No account or API key is needed.

Claude: add it as a custom connector, or paste the server URL into the connector settings yourself.

Claude Code:

claude mcp add --transport http nyc-sky-colors https://nyc-sky-colors.fcc.lol/mcp

Any other MCP client that supports Streamable HTTP can connect with the same URL.

Tools

get_current_sky_color

Returns the most recent sky colors in four directions: west, north-west, north-east and east. Takes no parameters.

Example result:

{
  "colors": {
    "west": "#6f8fb5",
    "north-west": "#7a9cc4",
    "north-east": "#84a7cf",
    "east": "#7d9fc6"
  },
  "timestamp": 1795712400000,
  "formatted": "11/26/2026, 12:00:00 PM"
}

timestamp is when the sample was taken, in Unix milliseconds. formatted is the same moment in New York local time.

get_sky_color_at_date

Looks up recorded sky colors for a past date. With a time it returns one sample; without one it returns every sample recorded that day.

Parameter Required Description
date Yes YYYY-MM-DD, in New York local time.
time No HH:MM, 24-hour, New York local time. Use a quarter-hour such as 14:30, since that is when samples are recorded.

Example result with a date and time:

{
  "date": "2025-09-29",
  "time": "00:00",
  "colors": {
    "west": "#08080e",
    "north-west": "#0c0c11",
    "north-east": "#0f0f15",
    "east": "#0b0a0f"
  },
  "timestamp": 1759118400000
}

Example result with a date only (a full day has 96 samples): 

{
  "date": "2025-09-29",
  "totalIntervals": 96,
  "intervals": [
    {
      "time": "00:00",
      "colors": { "west": "#08080e", "north-west": "#0c0c11", ... },
      "timestamp": 1759118400000
    },
    ...
  ]
}

If nothing was recorded for the date or time you ask for, the tool returns an error such as No data available for date 2024-01-01.

About the data

  • Colors are sampled from the live SUMMIT One Vanderbilt webcam published by EarthCam.
  • A new sample is taken every 15 minutes. Each color is the average color of a patch of sky in that direction, as a hex code.
  • Records begin in late September 2025.
  • Colors come from a camera, so they are affected by exposure, weather, glare and anything that passes in front of the lens.

Example prompts

  • What color is the sky in New York right now?
  • What did the sunset look like over NYC on October 12, 2025?
  • Build a color palette from yesterday's sky in New York.
